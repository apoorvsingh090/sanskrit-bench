# SPL-Bench — LLM-judge rubric (Sanskrit + Hindi)

`sara` / `lekhana` / `grounded-long` इत्येतेषां आधिकारिकं स्कोरं LLM-judge + मानव-ऑडिट इत्याभ्यां निर्धार्यते।
`src/evaluate.py` इत्यस्य token-F1 केवलं सूचनात्मकम्।

## Judge settings (v0.1.0, seed)

* Judge model: कोई भी प्रबल बहुभाषी मॉडल (उदा. GPT-4o / Gemma-3-27b-it)।
  पेपर/लीडरबोर्ड में judge का नाम + version + temperature अवश्य लिखें।
* Decoding: `temperature=0.0`, अधिकतम 512 टोकन, JSON-only output।
* Calibration: प्रत्येक ट्रैक पर 20 मानव-स्कोर्ड नमूनों से Cohen-kappa ≥ 0.6 लक्ष्य;
  5% मानव-ऑडिट अनिवार्य (C1/lekhana में 10% सुझावित)।

## Scoring (प्रत्येक 1-5)

* **शुद्धता (shuddhata)** — व्याकरणं, वर्तनी, सन्धि-समास-विभक्तयः शुद्धाः।
* **स्पष्टता (spashtata)** — विचाराः/तथ्यानि स्पष्टानि, विषये केन्द्रितानि, भ्रान्तिः नास्ति।
* **संगठना (sangathana)** — अनुच्छेदक्रमः, प्रवाहः, प्रारूपम् (पत्र/सूचना/संवाद हेतु)।
* **उपयुक्तता (upayuktata)** — शब्दसीमा, उद्देश्यम्, प्रयुक्तिः (औपचारिक/काव्य/व्यावहारिक) अनुरूपा।

```
कार्यम्: {track} | स्तरः: {level}

रब्रिक: शुद्धता, स्पष्टता, संगठना, उपयुक्तता — प्रत्येक 1-5।
दण्डः: तथ्यपरिवर्तने/नवीनसूचनायोजने स्पष्टता ≤2; उद्धरणहीने grounded-उत्तरे उपयुक्तता ≤2;
शब्दसीमा-उल्लङ्घने उपयुक्तता -1।
JSON: {"shuddhata": 1-5, "spashtata": 1-5, "sangathana": 1-5, "upayuktata": 1-5, "tippani": "एकं वाक्यम्"}
```

## Bias controls

* Verbosity: दीर्घतां स्वतः गुणं मा मन्यताम्; संक्षिप्त-समीचीनं > दीर्घ-भ्रान्तम्।
* Self-preference: judge स्वमॉडलपरिवारं न जानीयात्; blind ID इत्यनेन स्कोरं करोतु।
* Register: काव्य/शास्त्र/व्यावहारिक/IAST इत्येतान् विषयौपयिक्त्या परीक्षताम्, न निजरुच्या।
* Position: pairwise-तुलनायां क्रमं परिवर्त्य द्विवारं करोतु।
